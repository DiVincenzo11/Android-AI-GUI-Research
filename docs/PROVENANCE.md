# 来源与贡献边界

## 便携实现

`src/aigui/`、`tests/`、`fixture-app/`、构建脚本与示例适配器是本次独立整理实现。目标是把既有研究中的 UI/OCR 观察、入口候选、阶段采集、前台包检查和新输出验收机制变成可安装的小型工具，不是将整个本地历史研究原样发布。

历史研究中还包含应用专用适配器、OCR 变体、多种入口策略、模型调用、恢复规则及探索性批量运行。它们没有经过本版的可移植性与公开内容审查，不作为本版已交付能力。

## 历史案例

选择来自 `AI_firstuse_disclosure_v1` 诊断的 Otter、Perplexity、Brave 界面。公开数据保留原截图 SHA-256、采集 epoch、应用包名和导出说明，移除绝对路径与隔离用户环境信息。截图已人工查看，选用不含私人账号和会话内容的界面。

历史案例来源于真实设备实验，但不是本版生成的新实时实验，不构成三个应用上的自动发现或端到端成功率。

## v0.2.0 新实时实验

`artifacts/real-apps-v0.2.0/` 与上述历史案例不同，是 2026-11-01 使用本仓库执行器新采集的记录。测试对象为官方 Release 的 PocketPal、ChatterUI 和 DuckDuckGo APK；包版本、官方文件哈希和 Qwen 模型哈希均已核对。APKs、第三方源码、GGUF 与私人账号数据不包含在发布中。

精确适配器、多步点击、角色约束和 UIAutomator2 采集后端是便携工具本次扩展；实际被测应用和模型属于各自上游。两个本地应用使用同一个 Qwen 模型，不作为两个独立模型实验。Duck.ai 仅观察到其界面声明和响应，没有独立认证其服务端模型。

完整记录包含 16 次开发/验证尝试及失败边界。最终案例在适配器调试后选择；不是冻结测试集、首次尝试通过率、GUI 自动探索或完整 ScenGen 复现。模型导入、首次介绍和起始页面包含人工准备，必须连同实验文档说明。
