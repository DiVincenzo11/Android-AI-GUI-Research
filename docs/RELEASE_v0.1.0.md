# v0.1.0 — Portable research tooling and inspectable evidence

首次实验性发布：可安装 CLI、文本规则 AI 入口候选、目标包内受控交互、阶段 UI/OCR 观察、截图与录屏、nonce 新输出检查、失败日志、HTML 和 SHA-256 校验。

包含 Otter / Perplexity / Brave 的选定历史真实案例，以及原生 UI、UI + RapidOCR 两次真实 Android 测试应用执行记录。

13 项本机测试通过。测试应用回复为确定性 SIMULATED 文本；三个历史案例均未验证到新 AI 回答。没有发布跨应用准确率，没有宣称严格复现 ScenGen。上游、个人便携实现和历史诊断来源分别说明。
